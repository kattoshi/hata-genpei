# 旗源平点数早見表SPA

## 仕様
- Anguraをフレームワークとした SPA アプリ
- プロジェクトは、本README.md のフォルダーをワークスペースとする

- 旗源平の点数を即座に表示する SPA
- 使用されるのは、スマートフォンが多く、画面サイズもスマートフォンの縦置きで操作されることを想定する
- 上部に１投目のサイコロ数字と２投目のサイコロの数字を少ないタップ数で選択出来る選択肢を準備する。
- １投目と２投目の組み合わせで、下部に表形式で以下の情報を表示する  
   参考サイト:https://www.sakane.net/kanazawa/hatagenpei/hatagen1.htm
     - 唱え方
     - 貰える旗の種別と数
     - 点数換算
     - 連続投下  
         続けてさいころを振れる場合は「○」振れない場合は「×」

- クリアボタンを配置し、表を非表示にして、「サイコロの数字を入力して下さい」とメッセージ表示される

- Materialデザインなど取り込めれば良し
- プロジェクト名:hata-genpei

## 開発環境
- ホスト環境を汚したくないので、vscodeのdevcontainer配下で開発する
- nodeとangularは最新版を適用
- npm も最新版をセットアップするよう調整
- ソースコードには日本語で jsdoc コメントを積極的に使う
